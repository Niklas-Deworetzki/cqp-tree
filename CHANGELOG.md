# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

### Added

- Reverse-proxy support for web-server

## [1.0.0] - 2026-07-27

### Added

- Support for (no)Sketch Engine as a target
- Multiple corpora can be configured on one server
- Tutorial and documentation
- Permanent logging
- Pre-built docker images
- Translated queries can be used to search external systems

### Changed

- Web-client is now configurable to work with (no)Sketch Engine and Korp

## [0.2a1] - 2026-03-30

### Added

- Support for dep_search as an input language

### Fixed

- Port conflict for the web-server on macOS

## [0.1a1] - 2025-11-10

### Added

- Support for Corpus Workbench as a target
- Support for Grew as an input language
- Support for deptreepy as an input language
- Support for underspecified CoNLL-U files as an input language
- Web-client integrated with Korp
