Some more examples

If you have reached this page, you are probably wondering what kind of patterns you can search for with CQP/Tree. In this page, we have gathered a few examples in deptreepy/a> and Grew-match. You can copy-paste them into the web interface and run them on Korp's default corpus selection. With little to no adjustments, you can search for similar structures on any other dependency-annotated corpus hosted on Korp, or even on other CQL-compatible corpus search systems.

Compound tenses

Compound tenses are auxiliaries combined with other verb forms. For instance, you can use depsearch to look for ska + infinitive constructions: {% with name="expl1-depsearch", code="TREE_ (word ska) (msd VB\.INF.*)" %} {% include "snippet.html" %} {% endwith %}

or in Grew-match: {% with name="expl1-grew", code="""pattern { aux[word="ska"]; inf[msd=re"VB\.INF.*"]; aux->inf; }""" %} {% include "snippet.html" %} {% endwith %}

These queries are independent of the order of the two elements of the constructions, as well as of any intervening words between them.
