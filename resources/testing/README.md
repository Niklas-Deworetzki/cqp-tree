# Corpus Data for Integration Tests

This directory contains a verticalized version of the [UD MaiBaam corpus](https://github.com/UniversalDependencies/UD_Bavarian-MaiBaam) which can be directly ingested by Corpus Workbench and noSketch Engine.

- [configurations](https://github.com/Niklas-Deworetzki/cqp-tree/blob/main/resources/testing/configurations) contains the CQP/Tree configuration for the encoded corpus, defining names for annotation layers.
- [cqptree](https://github.com/Niklas-Deworetzki/cqp-tree/blob/main/resources/testing/cqptree) contains the verticalized (.VRT) file(s).
- [registry](https://github.com/Niklas-Deworetzki/cqp-tree/blob/main/resources/testing/registry) contains the corpus registry definition for the test corpus.
- [server.toml](https://github.com/Niklas-Deworetzki/cqp-tree/blob/main/resources/testing/server.toml) contains the CQP/Tree server configuration for integration testing.
